# Ergodic properties and growth-optimal asset allocation in stochastic factor markets

Reproduction code for the numerical experiments of

> X. Dong and E. V. Bulinskaya, *Ergodic properties and growth-optimal asset allocation in
> stochastic factor markets: invariant measures, limit theorems, and Kelly portfolios*.
> Faculty of Mechanics and Mathematics, Lomonosov Moscow State University.

Everything reported in Sections 7 and 8 of the manuscript — the closed-form ergodic
growth rate, the explicit Poisson corrector, the asymptotic variance, Figure 1, and
every number quoted in the text — is regenerated by the two scripts in this
repository. All runs use fixed seeds and are reproducible bit for bit.

## The model

The code implements the Ornstein–Uhlenbeck specialisation of Section 7:

```
factor         dX_t = -k X_t dt + eta dW^1_t
risky asset    dS_t = S_t[ (mubar + beta X_t) dt + sigma0 dW^2_t ]
riskless asset dB_t = r B_t dt
```

with `W^1` and `W^2` independent, so that `d = n = 1` and `m = 2`. The parameters of
Section 8 are

| symbol   | meaning                        | value |
|----------|--------------------------------|-------|
| `k`      | factor mean-reversion speed    | 2.0   |
| `eta`    | factor volatility              | 0.5   |
| `mubar`  | constant part of the drift     | 0.08  |
| `beta`   | factor loading of the drift    | 0.3   |
| `sigma0` | volatility of the risky asset  | 0.25  |
| `r`      | riskless rate                  | 0.02  |

## Installation

```bash
git clone https://github.com/dongx9815-bot/Xinrui.git
cd Xinrui
pip install -r requirements.txt
```

Python 3.9 or later. The only hard dependencies are NumPy and Matplotlib; SciPy is
optional and is used solely for the Kolmogorov–Smirnov goodness-of-fit test.

## Usage

```bash
python run_verification.py     # reproduces every number quoted in Sections 7-8
python run_figure1.py          # regenerates 02_fig_simulation.pdf (Figure 1)
```

Both scripts accept `--quick`, which reduces the horizon, the step count and the
number of paths for a fast smoke test (a few seconds). The full runs take roughly
ten seconds each on a laptop.

## What each file does

| file                  | contents |
|-----------------------|----------|
| `ergodic_kelly.py`    | the model, all closed-form quantities of Sections 6–7, and the Monte Carlo kernels |
| `run_verification.py` | four independent checks of the analytical results against simulation |
| `run_figure1.py`      | regenerates Figure 1 of the manuscript |
| `requirements.txt`    | pinned minimal dependencies |

### Correspondence with the manuscript

| object in the code                | manuscript |
|-----------------------------------|------------|
| `Model.kelly(x)`                  | Kelly feedback `pi*(x) = (mubar + beta x - r)/sigma0^2`, Eq. (34) |
| `Model.growth_function(x)`        | instantaneous growth function `g_pi(x)`, Eq. (10) |
| `Model.lambda_star`               | optimal ergodic growth rate `lambda*`, Eq. (35) |
| `Model.timing_premium`            | ergodic timing premium `beta^2 varsigma^2 / (2 sigma0^2)` |
| `Model.corrector(x)`              | Poisson corrector `phi*(x)`, Eq. (37) |
| `Model.poisson_residual(x)`       | residual of the Poisson equation, Eq. (32) |
| `Model.s2_star`                   | asymptotic variance `s^2(pi*)`, Eq. (38) |
| `simulate_terminal_growth`        | Euler–Maruyama simulation of the log-wealth decomposition, Eq. (9) |
| `clt_sample`                      | normalised errors entering Theorem 5.3 |

## Expected output

`run_verification.py` prints, among other things:

```
  optimal growth rate      lambda^*  = 0.0938
  static strategy rate  lambda(pi_c) = 0.0488
  asymptotic s.d.        s(pi^*)     = 0.39346

  sup residual over x in [-6, 6] = 1.066e-14

  sample mean = -0.00015   (s.e. 0.00393; 0.04 s.e. from 0)
  sample s.d. = 0.39361   (s.e. 0.00278; 0.05 s.e. from s(pi^*) = 0.39346)
  skewness         = +0.0629   (s.e. 0.0245)
  excess kurtosis  = +0.0452   (s.e. 0.0490)
  Kolmogorov--Smirnov test against N(0,1): D = 0.0108, p = 0.191
```

The residual of the Poisson equation vanishing to machine precision confirms the
explicit corrector of Eq. (37); the agreement of the sample standard deviation with
`s(pi*) = 0.39346` to within one twentieth of a Monte Carlo standard error confirms the
closed-form asymptotic variance of Eq. (38).

Diagnostics are printed to five significant figures so that the two standard-error
ratios can be recomputed from the printed values alone; Section 8 of the paper quotes
the same figures.

## Numerical scheme

The factor and the log-wealth are advanced jointly by the Euler–Maruyama scheme with
step `dt = 5e-3`, exactly as stated in Section 8. Paths are not stored: the simulation
streams, so memory is `O(number of paths)` rather than `O(steps × paths)`, which is
what makes the 10 000-path central limit theorem experiment inexpensive. For control,
`simulate_factor` and `simulate_terminal_growth` accept `exact=True`, which samples the
factor from its exact Gaussian transition law instead; the difference in the reported
statistics is well below the Monte Carlo error, confirming that the discretisation bias
is negligible at this step size.
